  conferencia_supabase_realtime_opcional.sql  Opcional (painel em tempo real)

COMO CONFIGURAR O config.js
  1) Supabase > seu projeto > Project Settings > API
  2) Copie o "Project URL" para SUPABASE_URL
  3) Copie a "Publishable key" (sb_publishable_...) ou "anon public" para SUPABASE_ANON_KEY
  4) NUNCA use service_role / secret key
  5) Suba o config.js no GitHub (mesma pasta) e abra  .../diagnostico.html  para conferir

    limpe os dados do site (F12 > Application > Clear site data) ou abra em aba anonima.
  - Faixa laranja no topo = Supabase nao configurado (config.js).
  - Uma faixa vermelha na parte de baixo da tela mostra o erro (ex.: config.js nao encontrado).
